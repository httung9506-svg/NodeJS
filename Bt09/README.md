# BÀI 09: XÓA DỮ LIỆU SINH VIÊN TRONG MONGODB

## 1. Giới thiệu
Sử dụng Node.js và MongoDB để thực hiện xóa dữ liệu sinh viên.

## 2. Các chức năng thực hiện
- Kết nối database qlsinhvien.
- Sử dụng collection students_test.
- Thêm ít nhất 5 sinh viên mẫu.
- Sử dụng deleteOne() để xóa sinh viên theo mã sinh viên.
- Sử dụng deleteMany() để xóa sinh viên có điểm dưới 5.
- Hiển thị số bản ghi đã xóa.
- Hiển thị danh sách sinh viên còn lại bằng find().

## 3. Cách chạy chương trình
Mở Terminal tại thư mục Bt09.

Cài đặt thư viện:
`npm install mongodb`

Chạy chương trình:
`node bai09.js`

## 4. Kết quả
Chương trình thực hiện xóa sinh viên bằng deleteOne() và deleteMany(), sau đó hiển thị danh sách sinh viên còn lại.
