# BÀI 1: QUẢN LÝ THÔNG TIN SINH VIÊN BẰNG JAVASCRIPT ES6

**Họ và tên:** Huỳnh Thanh Tùng

**Lớp:** Sinh viên

## 1. Mô tả bài tập

Xây dựng chương trình quản lý thông tin sinh viên bằng JavaScript ES6 và Node.js.

Các yêu cầu thực hiện:
- Khai báo danh sách gồm 5 sinh viên.
- Mỗi sinh viên có mã, họ tên, tuổi và điểm.
- Sử dụng class và constructor để biểu diễn sinh viên.
- Sử dụng arrow function kết hợp filter() để lọc sinh viên có điểm từ 5 trở lên.
- Hiển thị danh sách sinh viên đạt yêu cầu bằng console.log().

## 3. Cách chạy chương trình

**Bước 1:** Mở Visual Studio Code.

**Bước 2:** Mở Terminal và di chuyển đến thư mục Bt01:

```bash
cd bai03/bt01
```

**Bước 3:** Chạy chương trình bằng lệnh:

```bash
node bai01.js
```

**Bước 4:** Quan sát kết quả hiển thị trong Terminal.
