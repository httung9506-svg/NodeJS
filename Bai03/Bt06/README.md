
# BÀI 6: XÂY DỰNG MODULE TÍNH KẾT QUẢ HỌC TẬP

## 1. Giới thiệu
Xây dựng chương trình Node.js sử dụng Module để tính điểm trung bình và xếp loại học tập của sinh viên.

## 2. Các file trong chương trình
- bai06.js: Chứa dữ liệu sinh viên và hiển thị kết quả.
- xulyDiem.js: Chứa hàm tính điểm trung bình và xếp loại.
- README.md: Mô tả bài thực hành.

## 3. Chức năng
- Tính điểm trung bình 3 môn.
- Xếp loại học tập:
  + Giỏi: từ 8 trở lên.
  + Khá: từ 6.5 đến dưới 8.
  + Trung bình: từ 5 đến dưới 6.5.
  + Yếu: dưới 5.
- Sử dụng module.exports để xuất hàm.
- Sử dụng require() để gọi module.

## 4. Cách chạy chương trình
Mở Terminal tại thư mục Bt06.

Nhập lệnh:

node bai06.js

## 5. Kết quả
Chương trình hiển thị họ tên, điểm trung bình và xếp loại của 3 sinh viên trên Terminal.

## 6. Kết luận
Đã hoàn thành bài thực hành xây dựng Module tính kết quả học tập bằng Node.js.
